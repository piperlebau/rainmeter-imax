# Workspace launch slots

Each WS<N> folder holds up to 6 shortcuts — the launch bay (W11) reads them
via the FileView plugin, in name order. Edit these folders in Explorer to
change what a workspace launches; never touch skin code for this.

- Put `.lnk` shortcuts (or `.url` files) here, max 6 per folder.
- Order is by filename — prefix `1_ 2_ 3_` to control slot order.
- Fewer than 6 = remaining slots render as dashed EMPTY.

WS1 DEV · WS2 MEDIA · WS3 GAME · WS4 WRITE (editor mode) · WS5 DIAG

The .url files here are placeholders so the bay renders something on first run.
Replace with real shortcuts to your apps.
